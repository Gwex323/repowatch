# Spec Delta

## Purpose

让用户在录入供应商以及选择角色模型时直接查看并选用可用模型，减少重复输入，同时保留不支持模型列表的供应商的手工配置路径。

## ADDED Requirements

### Requirement: 在供应商表单选择模型
供应商表单 SHALL 展示名称、API 地址、接口、密钥和模型；模型框内的下拉按钮 SHALL 支持拉取并选入多个模型。保存后卡片 SHALL 展示名称、地址及已选模型。读取列表 MUST NOT 保存草稿或启动推理。

#### Scenario: 保存前拉取模型
- **WHEN** 用户填写 API 地址与密钥后显式请求模型列表
- **THEN** 界面展示可选模型，用户可以选入配置，再单独保存

#### Scenario: 拉取失败
- **WHEN** 供应商不返回可用模型列表
- **THEN** 界面仍允许手填模型，保留已输入的草稿

### Requirement: 为角色绑定选择供应商模型
角色配置界面 SHALL 固定展示处理 Agent 与审查 Agent 两个表单，各自选择供应商、模型并保存。模型下拉 SHALL 只提供所选供应商配置中已保存的模型，MUST NOT 请求远端列表。

#### Scenario: 选择已配置的模型
- **WHEN** 用户选择供应商，再从该供应商已配置的模型中选择
- **THEN** 界面将该模型填入绑定，直到用户保存才更新绑定
